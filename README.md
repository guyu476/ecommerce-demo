# ecommerce-demo

电商网站 Demo，基于 Next.js 全栈开发。

## 技术栈

- Next.js（React 全栈框架，支持 SSR / SEO）
- TypeScript
- Tailwind CSS

## 开发计划

- [ ] 项目脚手架搭建（create-next-app）
- [ ] 首页与商品列表页
- [ ] 商品详情页
- [ ] 购物车
- [ ] 结算与支付流程
- [ ] 用户登录 / 注册

## 本地开发

> 项目脚手架搭建完成后可用。

```bash
npm install
npm run dev
```

打开 http://localhost:3000 查看效果。
